# ¿Qué es y cómo se crea un archivo Markdown?

Markdown es una forma sencilla de escribir y organizar texto utilizando símbolos. En lugar de usar botones para dar formato, escribimos símbolos que indican cómo queremos que se vea el texto.
Un archivo Markdown se crea como un archivo de texto normal, pero se guarda con la extensión .md, por ejemplo: README.md.

Por ejemplo:

# Mi presentación

Mi nombre es Valery.

**Estudio Ingeniería de Sistemas.**

## Mis temas favoritos

- Programación
- Tecnología
- Matemáticas

GitHub interpreta estos símbolos y organiza el texto. Por ejemplo, # crea títulos, ** pone el texto en negrita y - crea listas.

# La licencia de software Licencia MIT:
Es muy breve y permisiva. Permite usar, modificar, distribuir y vender el software sin apenas restricciones, siempre que se incluya el aviso de autoría original.

# Apache 2.0: 
Es una licencia permisiva similar a la MIT, pero incluye explícitamente una concesión de derechos de patente y protege al usuario frente a demandas sobre patentes del creador original.

# GNU GPL (General Public License, v3 o v2):
Es una licencia de tipo copyleft. Exige que cualquier código modificado o trabajo derivado también deba distribuirse bajo los mismos términos de código abierto.
